Interactive Calculator

A premium dark calculator with keyboard support and a calculation history, built with HTML, CSS and JavaScript.

Overview

An interactive calculator with a minimalist dark design: a large display, clearly separated number and operator keys, and subtle hover and active states.

Problem and goal

Build a calculator that handles the edge cases (decimals, percentages, division by zero) and feels as good to use as it looks, with a mouse, touch or keyboard.

My role

Solo project. I designed the interface, wrote the layout and styling, and built all of the calculator logic in JavaScript.

Process and key decisions

  • A dark, restrained palette: near-black background, a slightly lighter surface for the calculator, a violet accent and near-white text.
  • A rounded container with number keys and operator keys visually distinct from each other.
  • Every key has an accessible label and a visible focus state, so it works without a mouse.
  • Keyboard support, so digits, operators, Enter and Backspace work as expected.
  • A calculation history so earlier results can be seen again.

What it does:

  • Number keys, addition, subtraction, multiplication and division
  • Equals, clear, and delete last digit
  • Decimals, percentage, and a plus/minus toggle
  • Division-by-zero handling
  • Keyboard support
  • Calculation history
