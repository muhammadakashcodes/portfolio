About me

I'm an IT student focused on web development. I learn by building: each project in this portfolio started as a question I wanted to answer, like how to pull live data from an API or how to make an interface feel polished.

I care about the details people notice without being able to name them: spacing, typography, contrast, and interfaces that work with a keyboard as well as a mouse.

Next, I'm moving into full-stack and mobile development, and I'm open to freelance projects where I can keep building and learning.
